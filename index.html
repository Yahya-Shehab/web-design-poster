تصميم صفحات الويب

من أول وسم <html> تكتبه، وصولًا إلى موقع كامل منشور على الإنترنت. تخصص يجمع بين البرمجة والتصميم، ويؤهلك لبناء مواقع حقيقية خطوة بخطوة.

console.log()

خطة التعلّم

curriculum.build
اضغط على أي مادة لعرض تفاصيل أكثر
01
HTML

بناء هيكل الصفحة

الأساس الذي تُبنى عليه كل صفحة ويب — العناوين، الفقرات، الصور، والروابط.

ستتعلم: الوسوم الأساسية، بناء نموذج (Form)، الجداول، والوسوم الدلالية (Semantic HTML) لبنية صفحة منظمة.
02
CSS

التنسيق والتصميم البصري

الألوان، الخطوط، والتخطيط — تحويل الهيكل إلى واجهة جميلة ومنظّمة.

ستتعلم: Flexbox وGrid لبناء تخطيطات مرنة، والتصميم المتجاوب (Responsive) لكل أحجام الشاشات.
03
JavaScript

إضافة الحركة والتفاعل

جعل الصفحة تستجيب لأفعال المستخدم — أزرار، نوافذ منبثقة، وتأثيرات حيّة.

ستتعلم: المتغيرات والدوال، التعامل مع الأحداث (Events)، والتحكم بعناصر الصفحة (DOM) مباشرة.
04
Bootstrap

تصميم متجاوب باحتراف

بناء صفحات تعمل بشكل مثالي على الجوال والحاسوب في وقت قياسي.

ستتعلم: نظام الشبكة (Grid System)، المكوّنات الجاهزة كالأزرار والقوائم، وتسريع بناء الواجهات.
05
PHP

برمجة جهة السيرفر

المنطق الخفي خلف الموقع — معالجة النماذج، وتنفيذ العمليات على السيرفر.

ستتعلم: استقبال بيانات النماذج، الاتصال بقواعد البيانات، وبناء صفحات ديناميكية تتغيّر حسب المستخدم.
06
SQL

إدارة قواعد البيانات

تخزين، تنظيم، واسترجاع بيانات المستخدمين والمحتوى بكفاءة.

ستتعلم: بناء الجداول، أوامر الإضافة والتعديل والحذف والاستعلام (CRUD)، وربط قاعدة البيانات بالموقع.
07
Deploy

رفع الموقع على السيرفر

إخراج مشروعك من جهازك الشخصي إلى الإنترنت ليصبح متاحًا للجميع.

ستتعلم: استضافة المواقع، نقل الملفات عبر FTP، وربط اسم النطاق (Domain) بالموقع.
08
Interactive

المواقع التفاعلية

تطبيق كل ما سبق في بناء مشاريع حيّة تحاكي مواقع العالم الحقيقي.

ستتعلم: دمج جميع المهارات السابقة في مشروع تخرج متكامل: موقع متكامل بواجهة وخلفية وقاعدة بيانات.
09
WordPress

إدارة المواقع الجاهزة

بناء وإدارة مواقع احترافية بسرعة، دون الحاجة لكتابة كل سطر كود يدويًا.

ستتعلم: تركيب القوالب والإضافات، وإدارة محتوى موقع متكامل دون الحاجة لكتابة كل الأكواد يدويًا.

مصمم واجهات (Front-End)

بناء واجهات المواقع التي يراها المستخدم ويتفاعل معها مباشرة.

مبرمج خلفية (Back-End)

بناء منطق الموقع وقواعد بياناته باستخدام PHP وSQL.

مستقل عبر الإنترنت

تصميم مواقع للعملاء وبيع خدمات WordPress عبر منصات العمل الحر.
